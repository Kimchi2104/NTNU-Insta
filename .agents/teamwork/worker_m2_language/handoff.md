## 2. Logic Chain
1. **基於 SOP 規範與影視傳播原理**：
   短影音旁白面向大眾與業餘同好，聽覺感知為線性不可逆之過程。若存在同音詞干擾（如 A-13 之「算雨/酸雨」、A-15 之「嚼子/餃子」、A-02 之「列肆/烈士」），受眾將瞬間產生認知斷層，因此必須提出明確消歧改寫建議。
2. **基於台灣繁體中文本色與專名規範**：
   作為國立臺灣師範大學天文社作品，詞彙量詞必須嚴格遵循台灣教育部與編輯出版規範（如「一個/一張簸箕」摒棄「一只」；「室女座」優先於「處女座」；「借來的」取代「抄來的」；「一天的忙碌/作息」取代「一天的活」；去除「被迫營業」等陸系網路詞彙）。
3. **基於定量語速與字卡邊界**：
   每格旁白語速 ≤ 4.5 字/秒與字卡 ≤ 14 字為強制合約規格。審稿中針對 H-七夕（> 6 字/秒）、A-01 開頭（6.17 字/秒）與各集開場/經文字卡（19–32 字）提出之修訂方案，均經程式嚴格核算字數，全數滿足 `card_chars <= 14` 與 `syllables/sec <= 4.5`。
4. **基於外語音韻學與配音實務**：
   非漢語專名（韓語諺文同化音變 Jingnyeo、阿拉伯文喉音與長音、因紐特語小舌音與雙母音、古北歐語無聲齒擦音 Þ）若無具體注音/音標與中文擬音指引，錄音現場必然癱瘓，因此建立完整配音發音提示為語言顧問審查之核心職責。

## 3. Caveats
1. **口播音變與方言習慣之彈性**：
   部分古天文音讀（如「角宿」之「角」讀 ㄐㄧㄠˇ 還是 ㄐㄩㄝˊ，現代國語審音以 ㄐㄧㄠˇ 宿為常，傳統字典亦收 ㄐㄩㄝˊ ㄒㄧㄡˋ），本報告建議大眾科普優先採 ㄐㄧㄠˇ ㄒㄧㄡˋ，若社內有特定古音傳統可經社務會議議定。
2. **外語擬音近似度之物理極限**：
   阿拉伯語咽音 ʿ（ʿayn）與因紐特語小舌塞音 [q] 屬於現代標準漢語及注音符號無法精確拼寫之音位，配音提示中已提供最貼近之擬音並補充發音技巧說明，錄音時宜以自然不生硬為最高原則。
