## 一、標題要改（11 集）

| 集 | 節目表原標題 | 建議標題 | 為什麼 |
|---|---|---|---|

| A-22 | 白俄羅斯：農民曆星空與 Elias 的馬車 | 白俄羅斯：農民曆星空與以利亞的馬車 | 中文標題用中文譯名 |

## 二、鉤子要改

| 集 | 原鉤子的問題 | 建議 |
|---|---|---|
| A-16 | 「只在冬天說」成立，但要限定 | 寫明是 Childrey 的說法；「初霜到初雷」出自納瓦荷的天文教育資料 |
| A-17 | 星星不是畫在帳篷門口 | 畫在帳篷頂端的黑帶上（McClintock p.218） |
| A-20 | 玄鳥不是朱雀（是燕子；商與大火有關） | 片中直說「朱雀沒有下過蛋」；標題可保留 |
| A-21 | Sarvvis 不是駝鹿 | 北薩米語是公馴鹿；片中說「公馴鹿，也有人說是駝鹿」 |
| A-22 | 「載乾草的車」無出處 | 「先是農家的大車，後來成了先知以利亞的火焰馬車」 |
| H-元宵 | 「天官住在星盤正中央」把信仰講成天文 | 「元宵拜的天官又叫紫微大帝——紫微，是星盤正中央那座天上宮城的名字」 |
| A-23 | 羅馬尼亞 39 個星座裡沒有羊圈 | 「天上有牧羊人、看羊的大狗、山羊一家，還有一口給羊喝水的井」 |
| A-24 | 「星座落下，雨季就來」不準 | 是一連串短汛（poero），各以黃昏落下的星座命名，有的反而帶來乾期；Pamõ 是犰狳不是蛇 |
| A-25 | 「30 個星座只留下 7 個」錯 | 書裡記了 28 個名字，然後說還有許多不寫了；鳥是美洲鴕，不是鴕鳥 |
| A-26 | 「航向世界」誇大 | 群島、馬來半島與澳洲北部 |
| A-27 | 「跟布吉斯共用海洋、不共用星座」與論文相反 | 「同一個北斗：布吉斯人看見船，曼達爾人看見漁網」 |
| A-29 | 「何時剪羊毛、何時收麥」無出處 | 小屋、鐮刀、葡萄串＝島上三種生計（Bussu） |
| A-31 | 「4–6 月完整現身」是澳洲看的 | 台灣只看得到身體和腳，頭（煤袋）在台北只升到 2.6° |
| A-32 | 「伊斯蘭曆法的 28 站」不成立 | 月站在伊斯蘭以前就有；伊斯蘭曆的月份從看到新月牙算起 |
| A-33 | 「唯一」 | 改「第一個承認毛利世界觀的國定假日」 |
| A-35 | 「一群人」劃界 | 「1930 年，一本書把天空切成 88 塊」（Delporte） |
| X-03 | 鉤子裡的「犁」沒有故事 | 改列十種：牛腿、車、熊、仙人、棺架、強盜、大蛇、船、漁網、獵物 |
| X-05 | 「水手認錯十字架會迷航」無史料 | 改用計算：把假十字當真十字，南方會偏 24°（東）到 42°（西） |
| X-07 | 因紐特的「雪橇痕」查無 | 因紐特叫 Aviguti「分界」；雪橇痕可能是 A-08「滑雪板痕」的誤記 |
