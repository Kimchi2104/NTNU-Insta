## 一、repo 端：生成優化版素材、腳本、逐字稿（每集都做，做完才動 Canva）

1. **資料核對**：`07_資料來源/` 的文化 CSV（原文、拼音、英文、中譯）先查一遍翻譯；錯的直接改 CSV 與 `01_星座連線筆畫.csv`，後面的腳本、標籤都從這裡讀。
2. **逐字稿 v2**：`04_腳本庫/{EP}-…-逐字稿-v2.md`，分鏡表一列一鏡：`| **01** Z | 秒 | 旁白 | 用檔／圖層 | 動作 |`。字數 ≤ 4.5 字/秒。
3. **星圖素材**：`make_{ep}_v4.py` → 大畫布（長圖）L1–L4…、北盤／南盤圖層組、`{EP}_鏡頭清單.json`（每鏡 frames、kind：Z/S/T/R）。
   跑 `check_disc_align.py` 確認「長圖上的北盤」和「北盤圖層組」逐點重疊（這是無縫換組的前提）。
4. **標籤／旁白**：`make_{ep}_labels.py`（或寫在 make_v4 裡）→ `{EP}_標籤資料.json`，鏡頭清單補 `vo`、`labels`、`overlay`、`overlay_layers`、`card`。
5. **概念圖**：`make_{ep}_diagrams.py` → `05_素材/{集}/_概念圖/`。方形分層圖（`…_星點層_透明.png`…）或 9:16 圖卡（`…_圖卡.png`）。**生成後一定要看預覽圖**：標籤互相疊字、壓到星點都要修（A-05 的六連星、キトラ內規就是這樣抓到的）。
6. **逐頁表**：`gen_canva_pages.py {EP}` → 逐頁製作表 csv/md、`Canva頁面參數.json`、逐頁標籤座標、描圖紙。
7. commit＋push 到工作分支（Canva 從 GitHub raw 連結匯入素材，所以要先推上去）。

## 二、頁面結構規則（gen_canva_pages 會自動做；手動排時照這個）

### 1. 同一鏡頭可以不只兩頁
- 基本是「鏡頭NN開始」「鏡頭NN結束」，兩頁之間 Match & Move。上一鏡結束＝下一鏡開始就共用一頁（頁名用「＝」）。
- Canva 單次轉場最長 2.5 秒：移動太長時 `--seg 2.5` 自動插「-中1、-中2」。
- **畫面不動的中間頁＝定格頁**，用來放概念圖（見 3）。
- **鏡頭與鏡頭之間預設 Match & Move（≤2.5 秒）**：在同一片天空裡滑到下一個構圖。只有腳本備註明寫【硬切】（例如從獵戶座跳回北方）才硬切。
  兩個構圖很接近還硬切＝畫面跳一下，比轉場更刺眼（A-07 北斗那一段就是）。

### 2. 長圖 ⇄ 北盤（不能讓觀眾看出換檔）
```
去程：…長圖（中心）→ 沿走廊往上 → 長圖停在北極（盤心置中）
      →「長圖轉北盤N」：同一格、只把長圖換成北盤（轉場：無）→ 北盤開始轉
回程：北盤最後一格 →「北盤轉長圖N-歸位」盤轉回 0°、回到換組那一格（Match & Move）
      →「北盤轉長圖N」：同一格、只把北盤換回長圖（轉場：無）
      →「北盤轉長圖N-下移」沿走廊往下回到出發點（＝去程倒放）→ 繼續長圖上的鏡頭
```
- 換組那兩頁畫面逐點相同（長圖上的北盤＝北盤圖層組），**轉場一定設「無」**：用 Match & Move 淡入淡出兩張相同的圖，中途星星會暗一下。
- 換組頁的前一頁如果有概念圖，要先有「-概念圖收」把概念圖收掉，再換組。
- 出發點＝往上那一鏡（T）的起格；北盤那段若不是從走廊上來，就先插「-回中心」「-上移」。

### 3. 概念圖＝定格頁
- 鏡頭有 `overlay` 就在該鏡**結束頁後**插：「鏡頭NN-概念圖1、2、3…」（分層圖一頁多疊一層）→「鏡頭NN-概念圖收」（淡出）。`overlay_at: "start"` 改插在開始頁後。
- 天空完全不動（同一格、同圖層），只有概念圖在變 → Match & Move 只會讓概念圖淡入／淡出。
- 方形分層圖：寬 1032、左 24、內容垂直置中；後面墊**團隊同款半透明黑底圓角框**（#000000、不透明度 75%、圓角 48），框只包住內容＋40px 留白。
- 9:16 圖卡：滿版 1080×1920，不加框。
- **概念圖頁不放星名標籤**（半透明框會透出字，和圖上的字打架）；「收」頁恢復該格的標籤。
- 字卡（`card`）目前寫在備註欄，照韓國集的做法用原生文字＋同款黑框做。

### 4. 每一頁都一樣的東西
- 背景：團隊漸層圖（media `MAHWs5D_MpY`），以頁面背景填入。
- **山的剪影每一頁都要有（包括北盤頁）**，位置 left −212.30、top 1622.44、1939.08×300.56，內圖框 0/0/1939.08×300.56（和團隊模板一樣）；換組時山才不會跳。
- 山的顏色：#343434→#000000、#4f4f4f→#404040。
- **地平線會升降的鏡頭**（鏡頭清單 `horizon: [緯度…]`，例：A-07 從烏蘭巴托 47.9° 升到台北 25°）：
  山的上緣放在逐頁表「地平線北點 Y」（`Canva頁面參數.json` 的 `mountain_top`），山下面補一塊黑色地面到頁底，
  整個山＋地面在頁與頁之間 Match & Move 上升。起格用第一個緯度、迄格用最後一個。
- 標籤一律原生打字（SVG 標籤在 Canva 解析度不夠）；字級限制在 36–96 px；大半在畫面外的不放。

## 三、Claude 在 Canva 的操作順序

1. `read-design` 開 transaction，讀 page_metadata＋presenter_notes 找出舊頁、要保留的頁。
2. 素材匯入：`upload-asset-from-url`，用 **commit SHA 的 raw 連結**（分支連結有 CDN 快取，剛推的新版會拿到舊檔）。媒體 ID 寫進 `{EP}_Canva媒體ID.json`。
3. `add_page` 一次加齊（新頁會加在最後）→ 讀回新頁 ID。
4. 每頁用 `canva_ops.py` 產生的 ops：背景 → 天空四層 → 山 → 標籤 → 概念圖框 → 概念圖 → 備註。
5. 補三個連接器的脾氣（下一批 ops 順便送）：
   - 山 `insert_fill` 後內圖框會多裁 1px → `crop_media` 回 0/0/1939.08×300.56；
   - `update_fill` 換圖後內圖框會被放大 → `crop_media` 回原尺寸；
   - `add_text` 後用回傳的 locator 送 `format_text`（字級、顏色、置中、行高 1.2）。
6. `reorder_page` 依逐頁表放到正確位置；用 `design_content` 讀回來比對頁序（presenter_notes 在 transaction 裡可能是舊的，別用它比）。
7. 看縮圖：換組前後兩頁要一模一樣；概念圖不疊字；山的位置一致。
8. 給你預覽 → **你說「存檔」才 commit**。

連接器做不到、要你手動的：刪頁、改頁面標題、設定轉場種類與秒數、雙色 SVG 換色（recolor 只能單色）、換品牌字型。

## 四、改過的東西怎麼重跑

```bash
cd 02_製作流程SOP
python3 make_a05_v4.py            # 星圖圖層、鏡頭清單（改鏡頭 frames 時）
python3 make_a05_labels.py        # 標籤、旁白、概念圖欄位
python3 make_a05_diagrams.py      # 概念圖
python3 gen_canva_pages.py A-05   # 逐頁表＋描圖紙
python3 canva_ops.py A-05 --list  # 看頁序與每頁要放什麼
```
重跑後 SVG 可能只有 matplotlib 的 id 變動：`git ls-files -m -z | grep -z '標籤.*\.svg$' | xargs -0 git checkout --` 還原。

## 五、Canva 連接器備忘

| 情況 | 做法 |
|---|---|
| 不能刪頁 | 舊頁移到最後，請你刪 |
| SVG 不能 update_fill（只收點陣圖） | 刪元素再 insert_fill；PNG 可以 update_fill，但要再 crop_media |
| recolor_element 只能單色 | 雙色的山交給你用「全部變更」 |
| 分支 raw 連結有快取 | 用 commit SHA 連結 |
| 大型讀取超過上限會存成檔案 | 用 python 解析存下來的 JSON |
| 儲存 | 一定要你在對話中說「存檔」 |

## 六、你存檔後的手工收尾（每集 5 分鐘）

1. **字型**：選任一個 Claude 打的標籤 → 字型換成品牌字 → 「全部變更」。
2. **山的顏色**：選一個灰色的山 → 顏色面板把 #343434 改 #000000、#4f4f4f 改 #404040 → 各按一次「全部變更」。
3. **轉場**：照逐頁表「與上一頁」欄設定：換組頁（長圖轉北盤、北盤轉長圖）＝**無**；其餘 Match & Move；概念圖頁時間跟旁白對齊。
4. 刪掉最後面上一集留下的舊頁；頁名如果還是舊的（例如「鏡頭01結束＝鏡頭02開始」）順手改掉。
