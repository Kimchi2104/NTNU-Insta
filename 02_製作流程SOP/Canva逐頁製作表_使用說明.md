# Canva 逐頁製作表・使用說明（給美宣／剪輯）

從 A-07 起，每集除了原本的圖層 SVG、鏡頭牆、鏡頭清單之外，多三樣東西。目的只有一個：
**讓每一頁在 Canva 裡「填數字、照描圖」就完成，不用再目測對位、不用再手點白點、不用再逐字打外文。**

```
05_素材/{集}/_v4大畫布/
  {EP}_Canva逐頁製作表.csv   ← 用 Google 試算表打開（一列＝Canva 一頁）
  {EP}_Canva逐頁製作表.md    ← 同上，手機上看方便
  {EP}_逐頁標籤座標.csv       ← 每頁每條標籤的位置、字級、顏色
  {EP}_標籤對照表.csv         ← 全集名詞：原文／拼音／英文翻譯／中文（直接複製貼上）
  {EP}_對位參考/P01_鏡頭01開始.png …   ← 每頁一張 1080×1920 描圖紙
  {EP}_L7-主角星白點.svg、{EP}_L8-主角星白圈.svg   ← 不用再手點白點
```

---

## 一、先疊好圖層組（跟以前一樣，每集做一次）

1. 大畫布：L1 銀河 → L2 星點 → L3 經緯線 → L4… 連線 → **L7 主角星白點** → 標籤層，逐層拉進來、設同寬、對齊置中、群組。
2. 北盤／南盤圖層組：同樣做一次（檔名 `{EP}_北盤L…`）。
3. **白點層（L7）放在連線層上面**：連線 0.30 寬會把 2 等星整顆蓋住，所以以前要手點白點。L7 就是主角星本身的白點，位置、大小跟 L2 一模一樣，只是疊在連線上面。L8 是細白圈，要「指認」某顆星時開。

## 二、照表做每一頁

打開 `{EP}_Canva逐頁製作表.csv`，每一列就是一頁：

| 欄位 | 怎麼用 |
|---|---|
| 頁名 | 沿用團隊慣例：`鏡頭01開始`、`鏡頭01結束`、`長圖轉北盤1`…。「＝」代表同一頁兩用（上一鏡的結束＝下一鏡的開始），不用做兩頁 |
| 圖層組 | 這頁用「長圖」（大畫布群組）還是「北盤／南盤」群組 |
| 寬 W／高 H／X／Y | 選取群組 → 位置 → **直接填這四個數字**（X/Y＝左上角） |
| 旋轉° | 盤圖層組才有。北盤負角＝逆時針＝時間往前 |
| 與上一頁 | `Match & Move（N 秒）`＝同一鏡頭內的移動；`無（硬切）`＝換鏡頭；`同框硬切`＝長圖轉北盤那一頁 |
| 留下的圖層 | 這頁要保留哪幾層；**其餘的連線層／標籤層在這頁刪掉**（以前靠記憶，現在照表） |
| 地平線北點 Y | 有地平線的頁：把山的剪影上緣放在這個 Y |
| 旁白（本頁起播） | 這頁開始要配的逐字稿，給打中文字幕的組員 |
| 概念圖、字卡 | 這頁要疊哪張概念圖、哪句字卡 |

### 長圖轉北盤（跟你們現在的做法一樣，只是數字算好了）

1. 做到表上「長圖轉北盤」的前一頁（例：A-07 的 P24，金樁置中、fov 48）。
2. 複製這一頁 → 新頁刪掉長圖群組、貼上北盤群組 → 填表上這一頁的 W/H/X/Y。
3. 兩頁之間**不設轉場**。畫面內容逐點相同（`check_disc_align.py` 驗證過：盤本體對不上 0 個），觀眾看不出換了檔。
4. 若表上寫「北盤→長圖不同框」，代表下一鏡是新構圖，直接硬切，**不用倒轉回去**；只有在表上寫「若要同框接回」時，才用你們的「複製、倒序、轉回 0°」做法。

## 三、標籤：原生打字，照描圖對位

SVG 標籤層在 Canva 裡解析度不夠，所以標籤一律原生打字（品牌字型也只能這樣）。

1. 把這頁的 `對位參考/P##_頁名.png` 拉進來，**設成全頁（1080×1920）放最上層**、透明度 50%。
2. 描圖紙上有：這頁該有的標籤虛影（**紅色小十字＝文字中心**）、主角星白圈、地平線、Reels 上下 250px 安全區（暗色帶）、頁頭數字、這頁的旁白。
3. 打字：外文與中譯從 `{EP}_標籤對照表.csv` 複製貼上（西里爾字母、阿拉伯文都不用自己打）；字級與顏色看 `{EP}_逐頁標籤座標.csv`。
4. 把文字中心對到紅十字 → 刪掉描圖紙。
5. 同一鏡頭的「結束」頁：複製頁面後，把每個文字拖到結束頁描圖紙的紅十字上，Match & Move 就會讓標籤跟著星星一起移動（平移／縮放時兩者都是直線內插，全程對得上）。
6. 旋轉鏡頭（R）裡不放原生標籤，或把標籤跟盤群組成一組（字會跟著轉歪）；表上 A-07 的旋轉段都沒有標籤。

## 四、重新產生（改了鏡頭之後）

```bash
python3 02_製作流程SOP/make_a07_v4.py          # 圖層、鏡頭清單、標籤資料
python3 02_製作流程SOP/gen_canva_pages.py A-07 # 逐頁表＋描圖紙
python3 02_製作流程SOP/gen_canva_pages.py A-07 --seg 2.5   # 若 Canva 轉場時間不夠長：自動插中間頁
```

`--seg 2.5` 會把每段移動拆成 ≤2.5 秒的多頁（中間頁的數字是 Canva 自己內插時會算出來的同一條路徑，接起來跟一段完全一樣）。

**舊集（A-01～A-06）也能跑**：只要資料夾裡有 `{EP}_畫布資訊.json` 和 `{EP}_鏡頭清單.json` 就會出逐頁表和描圖紙；但舊集沒有 `{EP}_標籤資料.json`，描圖紙上不會有連線和標籤虛影，旁白欄也是空的。要完整版，把舊集的 make 腳本照 `make_a07_v4.py` 補上 `vo`／`layers`／`labels` 欄與 `標籤資料.json` 輸出即可。
