# 萬國星空｜英文版製作流程（2026-11-01 起）

> 一句話：**英文版是「同一集中文 Canva 的副本，刪到 60–90 秒、字換成英文」**——星空、標籤、山、背景全部沿用，不重做素材。
> 規格與決定見 `英文版評估.md` 開頭「團隊決定（11/1）」；檔期見 `06_發布月曆/節目表_萬國星空_英文版.csv`；文字版型見 `01_視覺與品牌/字幕字卡版型.md`。

## 零、中文版與英文版的分工

| | 中文版 | 英文版 |
|---|---|---|
| 目的 | 完整、精確；放得進臺灣業餘天文聯盟 | 擴大觸及；讓沒看過系列的人停下來 |
| 長度 | 約 180 秒（已播的舊集更長，**不剪短版**） | **60–90 秒**（節慶短片 30–60 秒） |
| 內容 | 整個故事＋考據＋今晚抬頭看 | 一集只講**一個**故事；觀星指引改北半球通用說法 |
| 旁白 | 不配音：旁白＝畫面上的字 | 同左；英文每格 ≤ 2.5 words/sec |
| 平台 | FB、IG、YouTube、Threads | 同左；英文版也會貼進聯盟 |
| 檔期 | 週五 20:00 | 週三 21:00（大致是中文版播出後的那個週三） |
| 素材 | 自己生成 | **沿用中文版 Canva**，只改字、刪頁 |

## 二、流程（每集）

### 1. 英文稿（中文定稿之後才開始）

1. 前提：該集中文逐字稿是 **v1 或 v2（已查核）**，Canva 中文版已完成。
2. Claude 依 `外包任務書/03_英文版改寫.md` 寫 `04_腳本庫/_英文版/EN{nn}-{中文集}-{slug}-v0.md`（例 `EN01-A-11-Anuta-v0.md`）。分鏡表每格都要寫**沿用哪一頁中文 Canva**（頁名或頁號）。
3. 英文審稿看 v0，意見直接寫在同一份檔案最後的「Review」段（或交 `_審稿/EN01_審稿_{名字}.md`）；Claude 合併成 **v1**，v1 才能進 Canva。
4. 事實只能比中文版少、不能多：英文稿裡每一句都要能在中文定稿找到；中文版的限定語（「有人認為」「一說」）英文要保留。

### 2. 每頁英文文字表

Claude 從 v1 產 `05_素材/{集}/_英文版/EN{nn}_Canva逐頁文字.csv`：

| 欄 | 內容 |
|---|---|
| 中文頁號／頁名 | 沿用哪一頁（照中文版的 `{EP}_Canva逐頁製作表.csv`） |
| 英文字卡 | ≤ 6 個字（可空） |
| 英文字幕 | 已斷好行，每行 ≤ 36 個字母、≤ 2 行；太長的自動標「拆成 2 頁」 |
| 停留秒數 | 依英文稿 |
| 處理 | 留／刪／換概念圖（英文版 PNG 檔名）／改字 |

同時產 `EN{nn}_字幕.srt`（FB／YouTube 字幕軌）。

### 3. Canva：複製副本（回答「要不要 Make a copy」）

**要，而且要複製「同一集」的中文設計**（不是上一集，因為英文版要的就是這一集的星空頁）。做法：

1. 等英文稿 **v1 定稿**再複製（這時才知道要留哪些頁）。
2. 在**學校帳號**打開該集中文設計 → Make a copy → 改名 **`EN01 A-11 Anuta`**（英文集數＋中文集號＋英文短名）→ 分享給 kimjoo2104（可編輯）。
3. 建議在學校帳號開一個 Canva 資料夾「**萬國星空 EN**」，英文版都放進去，跟中文版分開。

為什麼不直接由 Claude 複製：Canva 連接器可以複製設計（甚至只複製指定的幾頁），但副本會變成私人帳號的檔案，團隊之後還要再分享回來、所有權也不在社團。照現行做法由學校帳號複製，所有權才在社團。

### 4. Claude 在副本裡做的事（跟中文版 SOP 第三節同一套工具）

1. `read-design` 讀頁序與備註，對照英文文字表決定每頁的去留。
2. **封面**：主標改 World Sky Cultures／萬國星空（小）／NTNU Astronomy Club；填空句改 *One sky. The ◯◯ saw — ◯◯.*；第二句改英文鉤子；加右上角標 **EN · EP01**（版型見 `字幕字卡版型.md` 第四節）。
3. **內容頁**：字卡、字幕換成英文素字（`add_text`＋`format_text`，位置照版型 EN-A／B／C）；備註改成英文旁白；星名標籤維持原文／英文（中譯標籤刪掉）。
4. **概念圖**：圖上有中文字的頁 → 換成英文版 PNG（`make_{ep}_diagrams.py --lang en` 重出到 `_概念圖/en/`）或整頁拿掉；純圖形的沿用。
5. **結尾**：下集見改 *Next Wednesday: …*；追蹤我們、參考文獻改英文；不用的頁**集中移到最後**（連接器不能刪頁）。
6. 預覽給你看 → 你說「存檔」才寫入。

### 5. 人工收尾（你＋美宣）

1. 刪掉最後面不用的頁；每頁停留秒數照英文文字表；轉場 Match & Move（換組頁「無」，跟中文版一樣）。
2. 字太多的頁：**複製同一頁、字分兩批**（背景不動），不要縮字。
3. 美宣套版型 EN-A／B／C、品牌字「全部變更」、封面。
4. 檢查每頁的字都在 Y 250–1670 內；封面文字在 Y 285–1635 內。

### 6. 音樂

- 上 YouTube 的版本用 **YouTube 音樂庫**或 CC0 的曲子（Canva 內建音樂在 YouTube 可能被 Content ID 認領）；四個平台同一首。
- 中、英文版可以用同一首，當作系列識別。

### 7. 匯出與發布

| 平台 | 格式 | 說明 |
|---|---|---|
| IG Reels | 1080×1920 MP4 | 封面選有鉤子那一格；Caption 第一行＝鉤子；出處放首留言 |
| FB Reels | 同上 | 可另上傳 `EN{nn}_字幕.srt` |
| YouTube Shorts | 同上 | 標題 ≤ 60 字元；說明 3–5 行＋出處；字幕軌上 SRT |
| Threads | 同上 | 第一句＝鉤子；不放 hashtag 牆 |

- 與中文版同一組帳號時，兩個版本至少**隔兩天**（英文版週三、中文版週五）。
- 發布後在 `節目表_萬國星空_英文版.csv` 的 FB／IG／YouTube／Threads 四欄填日期。

## 四、每集檢查表

- [ ] 中文版是 v1／v2 且 Canva 完成，英文稿才開工
- [ ] 英文稿 60–90 秒、每格 ≤ 2.5 words/sec、字卡 ≤ 6 字、每格有「沿用頁」
- [ ] 英文審稿看過（文法、名字拼法、原住民族名稱照來源拼寫）
- [ ] 觀星指引是北半球通用說法，沒有台北時刻
- [ ] 副本名稱 `EN{nn} {中文集} {英文短名}`，在「萬國星空 EN」資料夾
- [ ] 封面：英文主標、填空句、鉤子、EN 角標；文字在 Y 285–1635 內
- [ ] 概念圖沒有中文字殘留；中譯標籤已刪
- [ ] 下集見、追蹤我們、參考文獻是英文
- [ ] 音樂可用於 YouTube
- [ ] Caption、首留言出處、SRT 備好；節目表四欄填好
