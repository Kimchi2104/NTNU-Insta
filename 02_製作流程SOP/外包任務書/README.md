# 外包任務書（給 Gemini／Antigravity 等外部代理）

這個資料夾的每一份 `.md` 都是**可以整份貼給外部代理的完整指令**。代理只需要能讀這個 NTNU Insta 資料夾（或你貼給它的檔案內容）與上網。

## 工作流程

```
Claude 寫逐字稿 v0（04_腳本庫/*-逐字稿-v0.md）
   │
   ├─▶ 01_網路考據.md   （Gemini：把每集「⚠ 待查核清單」逐條查到出處）
   ├─▶ 02_審稿Critic.md （Antigravity：四個角色各自審一輪）
   │
   ▼  交件到 04_腳本庫/_審稿/
Claude 合併考據與審稿意見 → 逐字稿 v1（已查核）→ 星圖素材 → Canva
   │
   └─▶ 03_英文版改寫.md （英文版試點時才用）
```

## 交件規則（一定要照，Claude 才能自動合併）

- 一律寫到 `04_腳本庫/_審稿/`，檔名：`{編號}_{任務}_{代理名}.md`
  例：`A-16_考據_gemini.md`、`A-16_審稿-天文_antigravity.md`、`A-16_審稿-文化_antigravity.md`
- **不要直接改逐字稿本身**。意見寫在交件檔裡，由 Claude 合併，才能保留修改紀錄。
- 每條意見都要有：位置（鏡號或段落）、原文、問題、建議改法、出處（網址或書目＋頁碼）。沒有出處的意見請標「（推論）」。
- 交件後跟 Claude 說一聲就好：Claude 會直接從 Google Drive 的 `04_腳本庫/_審稿/` 讀（本地資料夾同步到 Drive 即可，不用打包）。

## 建議的分工

| 任務 | 適合的工具 | 一次給幾集 |
|---|---|---|
| 01 網路考據 | 會上網、會引用出處的研究型代理（如 Gemini 的深度研究） | 1 集 |
| 02 審稿（四角色） | Antigravity 開 4 個 agent，每個 agent 一個角色，同一集平行審 | 1 集 |
| 03 英文版改寫 | 任何擅長英文寫作的模型；之後一定要人工母語審 | 1 集 |

**一次一集**：一次塞好幾集，代理容易只審前面、後面草草帶過。
