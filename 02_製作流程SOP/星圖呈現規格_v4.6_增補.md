# 星圖呈現規格 v4.6 增補（接在 `星圖呈現規格_v4_大畫布.md` v4.5 之後）

v4.6 不改任何幾何；只加圖層、加欄位、加一支工具。舊集的 make 腳本不必修改就能照舊跑。

## 一、引擎（gen_master_canvas.py）

| 新增 | 說明 |
|---|---|
| `m.L_marks(hips, name="主角星白點", style="dot"\|"ring")` | 主角星標記層，疊在連線之上、標籤之下。`dot`＝與 L2 同位置同半徑（sz×1.5）的白點；`ring`＝半徑 max(1.1, 4r)、線寬 0.07 的指認細圈 |
| `m.D_marks(north, …)` | 盤檔對應版本，位置用 `pos_disc`，與大畫布逐點一致 |
| `m.build_discs(groups, label_sets, mains, line_sets=(), marks=())` | `line_sets=[(groups, name)]` 對應大畫布額外的 `L_lines(name=…)`；`marks=[(hips, name, style)]` 對應 `L_marks`。盤檔層序與大畫布相同：星點→連線→額外連線→標記→標籤 |
| `m.D_lines(north, groups, name="星座連線")` | 加 `name` 參數（預設不變） |
| `draw_mpl` 標籤 `clip_on=True` | 修正：鏡頭牆（sb_grid）的標籤以前不裁切，會漏到隔壁格，QA 時誤判 |

層序鐵則更新：**星點 → 連線 → 主角星標記 → 標籤**。

## 二、鏡頭 dict 新欄位（check_shots 忽略，給逐頁表用）

| 欄位 | 用途 |
|---|---|
| `vo` | 該鏡旁白全文（逐字稿分鏡表直接由此產生，避免兩處不一致） |
| `layers` | 要留下的連線層 key（`"L4"`＋`標籤資料.json` 的 `lines` 對照） |
| `labels` | 要開的標籤層名稱（＝L_labels 的 name） |
| `labels_end` | 鏡頭最後一格改開的標籤層（同位置兩版逐格切換，例：A-07 06 鏡循環版→折返版） |
| `overlay`／`card` | 要疊的概念圖檔名／字卡文字 |
| `horizon` | R 鏡頭的地平線緯度（可多個，Match & Move 移動山剪影）；逐頁表算出北點 Y |

make 腳本另輸出 `{EP}_標籤資料.json`：`label_sets`（每層每條的錨點、偏移、色、字級）、`terms`（名詞總表：原文／拼音／英文翻譯／中文／來源）、`cross`、`mains`、`lines`、`line_groups`。

## 三、gen_canva_pages.py（新工具）

讀 `畫布資訊.json`＋`鏡頭清單.json`＋`標籤資料.json` → 出 Canva 逐頁製作表、逐頁標籤座標、標籤對照表、每頁 1080×1920 對位參考圖。

- 頁序規則：鏡頭內起→迄＝Match & Move；鏡頭間＝硬切；**同框同組**兩頁合併（「鏡頭05結束＝鏡頭06開始」）；**同框換組**＝`長圖轉北盤n`（前頁複製只換群組，不設轉場）。
- Canva 位置：長圖 `W＝360/fov×1080`、`X＝540−(cx−x0)·u`、`Y＝960−(y1−cy)·u`；盤 `W＝H＝2R_fill·u`、左上＝盤心螢幕位置−W/2。X/Y＝未旋轉時左上角；旋轉以元素中心為軸。
- 盤頁上的點：盤內局部座標先旋轉 `−rot`（Canva 正角＝順時針），與 `sb_grid` 的「lst→lst−rot」等價。
- 地平線（固定在畫面上）：`lst_obs＝(lst−rot)−180`，以 `horizon_points(φ, lst_obs)` 投到旋轉後的盤；北點＝盤心正下方 kφ。
- `--seg s`：每段移動拆成 ≤s 秒的中間頁；內插在 Canva 元素空間（寬 ∝ 1/fov 線性、中心/fov 線性、旋轉線性），與 M&M 本身的內插同一條路徑。

## 四、新規則：R 鏡頭單段旋轉 < 180°

Canva 的 Match & Move 遇到 >180° 的旋轉，可能走最短路徑、反方向轉（北盤＝時間倒流）。

- **每一段 M&M 的旋轉量必須 < 180°**。需要更大時用 `--seg` 拆頁，或改 lst。
- 要停在「某日某時面向北方」的畫面：`rot＝−((LST_觀測＋180−lst) mod 360)`。A-07：LST(10/2 20:00 台北)=312.6°，lst=305 需 −187.6°（超過），改 lst=322 → −170.6°。
- 選 lst 時連同這條一起評估（第三節「每集必須個別評估」表加一列）。

## 五、QA 清單增補

- 看 `對位參考/`：每頁的標籤虛影不壓連線、不出安全區；原文／中譯要同時開時必須上下兩行（`TERM_DY2`），不要同位置。
- 相鄰星距 < 2°（例：獵戶腰帶三星 1.4°）不要每顆都上標籤。
- 只有 Stellarium 一個來源的星座名，旁白要講出「Stellarium 的資料」；本地資料與 Stellarium 衝突時，以本地辭典／民族誌為準並在片中說明（A-07：三頭鹿＝獵戶腰帶，不是夏季大三角）。
