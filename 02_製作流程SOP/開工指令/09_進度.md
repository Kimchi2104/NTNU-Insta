# 卡 09｜現在到哪一步（進度板）

進度不用問任何對話。`06_發布月曆/進度板.md` 是 `02_製作流程SOP/進度.py` 從 repo 的檔案算出來的：每一集在循環的哪一步、下一步要貼什麼。每張卡結束、每次交件 push 之後都會重算。

## 看進度（三種，由便宜到貴）

1. **手機**：GitHub 打開 `06_發布月曆/進度板.md`。
2. **Antigravity**（用 Credit）：一般對話貼
   ```
   終端機跑：git pull --ff-only origin main && python3 02_製作流程SOP/進度.py && git add 06_發布月曆/進度板.md && git commit -m "進度板" && git push origin main
   然後把「現在先做」那一節貼給我。
   ```
3. **Claude**（Sonnet 5.5／low，很小）：
   ```text
   【卡 09 進度】
   先讀 02_製作流程SOP/開工指令/README.md 第三節。跑 /usr/bin/python3 02_製作流程SOP/進度.py，把 06_發布月曆/進度板.md commit、PR、合併；最後一則訊息只貼「現在先做」那一節。
   ```

## 進度板看不出來的

- ⑨ 收尾、發布、Ⓖ 收尾是手工，進度板只會一直顯示「收尾、發布」；發布後用卡 08 把節目表狀態欄寫「已播 YYYY/MM/DD」，過了發布日它就自動不列了。
- Canva 副本有沒有複製好：進度板不知道，卡 04／07 開工時會去找設計名，找不到會回報。

## 對話怎麼管

- **Claude 對話**：每張卡開工就改名「卡 0N｜集號 短名｜做什麼」，結束「✓ 卡 0N｜…」。列表裡沒有 ✓ 的就是還在做或中斷的。
- **總控對話**：只留一個，名字「總控」，問流程、改文件、改規則用它；不在裡面做卡。
- **Antigravity 對話**：第一行寫「【A-22 考據】」「【A-22 審稿-天文】」「【EN03 英文審稿】」；一集一個對話，做完就不再回去。
- 做完的對話不用刪，靠名字分辨。
