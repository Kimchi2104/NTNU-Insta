# 卡 08｜雜務（節目表、CSV、文件）

- 模型：**Sonnet 5.5／effort low**　預估：很小
- 用在：發布後填日期、改節目表鉤子或標題、補譯名表、修文件、記用量

## 貼給 Claude（整段複製，把要做的事列清楚）

```text
【卡 08 雜務】
要做的事（一行一件）：
1. 
2. 

這個對話只做上面列的雜務，不碰逐字稿內容。先讀 02_製作流程SOP/開工指令/README.md 第三節「共同規則」。
規則：CSV 用 python 改，保留原檔的 BOM 與換行（兩份節目表是 BOM＋LF；07_資料來源/_整理CSV/Arabic Ancient.csv 是 BOM＋CRLF）；改節目表的鉤子或標題時同步看 00_企劃藍圖 與英文節目表有沒有引用；每集做完的對話數與模型記在節目表備註欄。
結束：commit、PR、合併，回報一行一件。
```
