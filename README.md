## 版本與命名

- 逐字稿：`v0` 初稿（待查核）→ `v1` 已查核（可進 Canva）→ `v2` 外部審稿合併後。舊版不刪，留在同一資料夾。
- 集號：A-01…（萬國星空）、C-01…（深度番外）、X-01…（環球特輯）、H-（節慶）、B-（出隊預告）；英文版 EN01…（對應的中文集寫在英文節目表）。
- Canva 設計：中文 `A-11 阿努塔`；英文 `EN01 A-11 Anuta`（學校帳號，資料夾「萬國星空 EN」）。
