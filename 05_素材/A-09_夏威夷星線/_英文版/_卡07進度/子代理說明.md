# EN48 Canva 英文：子代理說明（卡 07，設計 DAHZrcch6yc「EN48 A-09 夏威夷」）

你要在 Canva 設計 `DAHZrcch6yc`（1080×1920，共 45 頁）把**你這一批的頁面**放上英文。只動你這批的頁，其他頁不碰；**不要 reorder_page**（主對話最後做）。封面（1）、端卡（43）、追蹤頁（44）主對話已改完並存檔，不要動。

## 先讀
- `05_素材/A-09_夏威夷星線/_英文版/_卡07進度/pages.json`：每個要排的頁，欄位 `design_page`（設計裡的實際頁號，read-design／edit-design 的 page_index 用這個）、`page_id`、`seq_page`（英文稿 Page sequence 的原頁號）、`headline`（字卡）、`body`（字幕，已斷好行，換行照用）、`pos`（top／bottom）、`plan`（這頁要做的特殊事）、`notes`（要寫進備註的整句，原樣貼）。
- 版面規格（Y＝文字框上緣，1080×1920）：
  - 字卡：白字 **72 px 粗體**、行高 1.15、框寬 860、X 110；上方放 Y 262，下方放 Y 1290。≤ 18 個字母才可用 84 px（不要用）。
  - 字幕：白字 **44 px**、行高 1.3、框寬 860、X 110；上方：有字卡放 Y 372、沒字卡放 Y 290；下方：沒字卡放 Y 1360、有字卡放 Y 1375。用 `\n` 照 pages.json 的斷行。
  - 窄框（全寬框會壓到星名標籤、主角星、概念圖時才用）：同一側改窄——左 X 110 或右 X 520，寬 500–600；字卡 56–64 px 粗體（可 2 行）、字幕 38–40 px，每行 ≤ 28 個字母、最多 4 行（字不變，只改斷行）。Y 依該頁空處。
  - 字幕框底緣要在 Y 1580 以內；字卡／字幕不要壓到標籤與主角星；概念圖頁只放字卡（pos＝top），字幕沒有就不放。

## 做法（每一頁）
1. 開 transaction：`read-design`（design_id=DAHZrcch6yc，`open_transaction: true`，`filter.fields: ["design_content","thumbnails"]`，`page_indices` 和 `thumbnail_pages` 填你這批的頁）。內容很大，會存成檔案時用 `/usr/bin/python3 -I` 解析（找每頁 `elements` 的 `locator_id`、`type`、`textRegions.characters`、`fill.media.mediaId`／`altText`）。
2. 該頁原有的**中文字幕／字卡文字框**（字級約 69 px 的中文句子）**全部刪除（delete_element）**；為字幕墊底的黑色半透明矩形（type shape、opacity 0.75、黑色）也**刪除**。新字用 `add_text`（`page_id`、`left`、`top`、`width`）新增，再用回傳 locator 送 `format_text`（font_size、font_weight bold／normal、color #ffffff、text_align start、line_height）。
3. 星名標籤（Hōkūleʻa、Ka Iwikuamoʻo 等夏威夷名與 Mintaka 等）**不動**；中譯標籤用 `replace_text` 換英文（必要時 `resize_element` 加寬、`position_element` 對回星點，標籤原本置中的就保持置中，也就是調整 left 讓中心點不變）：

   | 中文 | 英文 |
   |---|---|
   | 大角星／角宿一 | Arcturus／Spica |
   | 脊椎骨 | the backbone |
   | 南十字 | Southern Cross |
   | 北極星 | North Star |
   | Makaliʻi 的舀水杓 | Makaliʻi’s bailer |
   | 酋長的釣線 | the chief’s fishing line |
   | Kawelo 的風箏 | Kawelo’s kite |
   | 五車二／北河二／北河三／南河三／天狼星 | Capella／Castor／Pollux／Procyon／Sirius |
   | 參宿三／獵戶座 | Mintaka／Orion |
   | 昴宿星團 | the Pleiades |
   | 西伯利亞：鴨巢／西伯利亞：打穀者 | **整個標籤連同它的星點標記一起刪除**（英文版沒有西伯利亞） |

   `plan` 欄會再說某一頁有哪些標籤；遇到表上沒有的中文標籤，照上表風格自己譯成英文並在回報裡列出。
4. 概念圖頁（`plan` 有 concept／diagram 字樣）：原有的中文概念圖元素（fill.media.mediaId 為 `MAHXD-Lpa2w` 島嶼層、`MAHXD-WRcww` 航線層、`MAHXD4ILXbs` 天頂星層、`MAHXD1O3UVg` 南十字層）改用英文版，用 `update_fill`（asset_type image）＋立刻 `crop_media`（寬高都給：top 0／left 0／width 1032／height 1032，若元素實際寬高不是 1032 就用元素原本的寬高）：

   | 原圖 | 換成（asset_id） |
   |---|---|
   | 島嶼層 MAHXD-Lpa2w | `MAHcI9gZCKU` |
   | 航線層 MAHXD-WRcww | `MAHcI9NYyYs` |
   | 天頂星層 MAHXD4ILXbs | `MAHcI1pBlxM` |
   | 南十字層 MAHXD1O3UVg | `MAHcI1CwC7E` |

   三角層（`MAHXD4q2EIA`）若出現在你的頁，刪除。alt_text 寫英文簡述。換完 `position_element` 確認圖框位置跟原本一樣。
5. 北盤頁／長圖頁的紅色指針層（altText 含「L9-連線-指針」）：只有 `plan` 寫「hide the red pointer layer」的頁才刪除（delete_element）。
6. 備註：`replace_speaker_notes`，內容**原樣貼 pages.json 的 `notes`**。
7. 每頁編輯後看回傳的縮圖：字沒出框、沒壓到標籤與主角星、沒壓到概念圖；會壓到就改窄框或移位置，**不改字**。全批做完、縮圖都 OK 才 `finalize: "commit"`（commit 前確認每頁都有看過縮圖）。
8. 連接器脾氣：`add_text` 後要用回傳的 locator 才能 `format_text`；`update_fill` 後要 `crop_media`；一次 edit-design 呼叫只能改一頁（page_index），但同一頁的多個 operation 可以放一起；每次回傳都是整頁文件（很大），不要貼回來。

## 回報（只回這張短表，不要貼頁面內容）
`頁號（design_page / seq_page）｜OK／哪裡有問題｜用了窄框嗎（哪一側、寬）｜字卡與字幕實際 X/Y/字級｜翻了哪些標籤／刪了什麼｜Pos 跟稿不同嗎（稿寫 top/bottom，實際放哪）`。最後一行寫 transaction 是否已 commit。
