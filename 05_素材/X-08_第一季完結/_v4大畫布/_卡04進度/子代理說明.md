## 一批的流程（每批 6–8 頁，一次一個子代理，不要平行）

1. `read-design`（design_id DAHXDilvnmY，open_transaction true，filter.fields=["page_metadata"]，page_indices 只給本批第一頁）開 transaction。
2. 每頁產生 ops（把本批頁號、ID 填進去；ID 從 page_ids.txt 取）：
   ```
   cd /home/user/NTNU-Insta/02_製作流程SOP
   /usr/bin/python3 canva_ops.py X-08 --pages 5,6 --ids 5=PBxxx,6=PByyy      # 背景→天空層→山→標籤(add_text)→概念圖框→概念圖→備註
   /usr/bin/python3 canva_text_ops.py X-08 --pages 5,6 --ids 5=PBxxx,6=PByyy # 字卡＋字幕的 add_text 與 format
   ```
   （`canva_ops.py` 要先有 `X-08_Canva媒體ID.json` 的 `layers/concept`；沒有就回報，不要自己上傳。）
3. **一頁一個 edit-design 呼叫**（page_index = 頁號+1，finalize keep_open）。第一批 ops ＝ canva_ops 的全部 ops ＋ 緊接著 canva_text_ops 的 `add`（字卡、字幕，接在標籤 add_text 之後、備註之前或之後都可以）。
4. 回傳的 document 裡找：
   - 山（rect，mediaId `MAD4KTwSGtw`）→ 補 `{"type":"crop_media","locator_id":<山>,"left":0,"top":0,"width":1939.08,"height":300.56}`
   - 每個新 add_text（依序＝標籤、字卡、字幕）→ 各補一個 format_text：標籤用 `canva_ops.label_items` 同一份字級／顏色（`label_format`）：進 python 取 `canva_ops.label_items(labels)`（labels＝`X-08_逐頁標籤座標.csv` 該頁的列），字卡、字幕用 `canva_text_ops` 輸出的 `format`
   - 同一個第二批 edit-design 一次送完（crop＋所有 format_text）。
   - 連接器脾氣：山 insert_fill 後 crop_media 要回 0/0/1939.08×300.56；add_text 後要用回傳的 locator 才能 format_text；update_fill 換圖後 crop_media 寬高都要給。
5. 沒有標籤、字卡、字幕的頁就只有山要 crop。有 overlay（概念圖）的頁，圖框（半透明黑圓角）在概念圖下面、概念圖＝insert_fill（canva_ops 已排好順序）；概念圖頁不放星名標籤（逐頁標籤座標已處理）。
6. 看每頁縮圖（每頁一次）：天空有星、山在頁底、字不疊在山上、概念圖沒被字蓋住。有問題就用 position_element／delete_element 修，修不了就記下頁號。
7. 本批全部排完 **commit transaction**（`finalize: commit`，不帶 operations）。
8. 最後只回一張短表：`頁號｜OK／哪裡有問題`，不要貼頁面內容或 ID。

- 不要改 repo 檔案、不要動其他頁（封面、下集見、追蹤我們、參考文獻都不要碰）。
- 山每頁位置一致：left −212.30、top 1622.44（`mountain_top` 有值的頁用該值，canva_ops 已處理）。
