# A-33 卡 04｜子代理說明（內容頁分批排）

你是被主對話開來排「一批內容頁」的子代理。**用 Canva 連接器（read-design／edit-design）；如果這些工具你這邊用不了，立刻回「無法使用 Canva 連接器」並結束，不要自己硬排、不要改別的檔。**

## 設計與頁序
- 設計：`DAHXDo_Ghfw`（A-33 毛利），目前 66 頁。**不要 add_page、不要 reorder、不要刪頁**，頁序在全部排完後由主對話調。
- 每個「內容頁 N」對應的 page id 與設計頁序（page_index）在同資料夾 `page_ids.txt`（內容頁 N＝設計第 32+N 頁）。這些頁目前是空白頁，已有頁名。

## 怎麼產生 ops（不要手寫）
在 repo 根目錄：
- `/usr/bin/python3 02_製作流程SOP/canva_batch_ops.py A-33 build {頁號}` → 這一頁的 ops（JSON）；原樣放進 edit-design 的 operations，`page_index` 用 page_ids.txt 的設計頁序，`transaction_id` 用你自己開的。
- 回傳的 `document` 裡找：①「山的剪影」那個元素（mediaId `MAD4KTwSGtw`，type rect）的 id；②文字元素（type text）的 id，依出現順序。然後
  `/usr/bin/python3 02_製作流程SOP/canva_batch_ops.py A-33 fmt {頁號} {山id} {文字id…}` → crop_media＋format_text ops，再送一次 edit-design。**可以把這一頁的 fmt ops 併進下一頁 build 的同一次呼叫**（ops 可以跨頁，locator 帶頁前綴）以省呼叫；最後一頁的 fmt 單獨送。
- 只做你被指派的頁號，不要動別頁。

## 流程
1. `read-design`（design_id=DAHXDo_Ghfw，open_transaction=true，fields=["design_metadata"]）取得 transaction_id。**不要讀整份設計。**
2. 逐頁 build → 讀回 document → fmt（上面）。
3. 這批全部做完後，`read-design` 取這批頁的縮圖（thumbnail_pages，一次講完），檢查：每頁都有山、概念圖頁沒有字蓋到圖、字卡與字幕有顯示（白字置中）、同一格的前後頁看起來一樣。有問題先修。
4. `edit-design` finalize=commit。
5. 在 `_卡04進度/進度.md` 追加一行「內容頁 a–b 完成（子代理）」，`git add` 該檔、commit、`git push origin claude/card04-a33-canva`。

## 連接器脾氣（腳本已處理，知道就好）
