# 英文版逐字稿

- 檔名：`EN{nn}-{中文集}-{slug}-v{n}.md`（例 `EN01-A-11-Anuta-v0.md`）。`EN{nn}` 照 `06_發布月曆/節目表_萬國星空_英文版.csv`。
- v0＝Claude 依中文定稿（v1／v2）改寫；v1＝英文審稿看過。只有 v1 可以進 Canva。
- 規格：`02_製作流程SOP/外包任務書/03_英文版改寫.md`（60–90 秒、一集一個故事、≤ 2.5 words/sec、每格標沿用的中文頁）。
- 流程：`02_製作流程SOP/英文版製作流程.md`。
- 譯名：`06_發布月曆/英文譯名表.csv`，一詞一譯。

## `_舊草稿_2026-10/`

2026/10 依**舊規格**（180 秒、有配音、放 YouTube／FB）寫的 9 份草稿（A-01～A-04、A-06、A-13～A-15、H-七夕），**沒審過，內容有錯**（例如依照查核報告更正前的中文版）。不要直接用；寫新版時可以拿來參考句子，但每一句都要對回中文定稿。
